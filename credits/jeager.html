Who and what is in this game.

Images and code

The images were made with an AI pixel-art generator and then edited by us. The code was written with the help of AI assistants (Claude by Anthropic), directed and tested by the maker.

No third-party libraries in the game itself.

Sound

Sound: generated in code (WebAudio); no recordings or sound files from others.

The aircraft type names (F-16, F-35, Su-27, Tu-95) are names of real aircraft, used descriptively; there is no connection with their makers.

Fonts: your device's system fonts; no font is shipped.

Galadin is a small independent studio from the Netherlands.
